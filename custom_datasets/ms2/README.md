# MS2 Dataset for AnyThermal

No extra post processing is required for MS2 dataset. The dataset can be used directly after downloading.

## Downloading the Data

Follow [this](https://sites.google.com/view/multi-spectral-stereo-dataset/download?authuser=0) to download the freiburg dataset.

Use the root directoery (where you extract the `odom`,`proj_depth` and `sync_data` folders) path in the `<ANYTHERMAL_ROOT_DIR>/custom_datasets/dataset_path.yaml` file to point to the root location of the extracted data.
